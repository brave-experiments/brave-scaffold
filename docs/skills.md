# Skills

Skill source lives in `skills/`. Relative links in `.agents/skills/` expose the
skills to this repository; `.claude/skills` links to the same discovery directory.

- [simplify-code](../skills/simplify-code/SKILL.md): Find duplicated logic and
  remove needless code and structure while preserving behavior and making the
  result easier to understand.
- [testing-preflight](../skills/testing-preflight/SKILL.md): Choose tests that
  catch meaningful faults without adding redundant checks.
